# Agent instructions

Before starting any task, read `docs/MEMORY.md`, `docs/UPDATE_RELEASE_CONTRACT.md`, and every document in `docs/` relevant to the requested work. Treat these documents as durable project memory. `docs/UPDATE_RELEASE_CONTRACT.md` is mandatory for every new agent and conversation; it is the highest-priority project contract for update, toolbox, installer, uninstall, and release work.

Before handing off every task, record its completed work, current state, and any changed decision in `docs/MEMORY.md`. Update the relevant document in `docs/` when the task changes a project decision, workflow, version, packaging rule, or acceptance criterion.
