# CAD_translator

### 🚀 项目简介
这是一个基于 `pydxf` 的 CAD 翻译小工具，专为机电专业设计。<br>
能帮你快速搞定图纸里的外文翻译，省去手动查词、手动修改的麻烦。

---

### ⚠️ 注意事项 (必读)

1. **必须转为 DXF：** 软件只认 `.dxf` 文件。<br>
   如果是 `.dwg` 格式，请先在 AutoCAD 里选“另存为” DXF。
2. **天正软件的坑：**<br>
   天正导出的 DXF 偶尔会有文字乱码问题，这是软件编码差异导致的，请见谅。
3. **DeepL 翻译：**<br>
   内置了机电行业的常用词汇表，翻译更专业。使用前请记得配好你的 DeepL API Key。
