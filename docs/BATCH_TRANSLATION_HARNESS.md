# 批量 CAD 翻译队列：实现与验收 Harness

## 目标

在现有单文件翻译流程上增加可恢复的批量队列，支持 DXF/DWG、四种语言方向、可控并发、失败重试和每个任务的明确结果。

## 队列模型

每项任务保存以下不可变输入：源文件绝对路径、输出目录、输出格式与版本、是否翻译块、入队顺序；批次保存统一的语言方向。每项保存以下运行状态：`queued`、`running`、`paused`、`retrying`、`succeeded`、`failed`、`cancelled`。

- 同一批队列只翻译到一个目标语言；切换语言只作用于尚未开始的任务。
- 默认按入队顺序调度；用户可暂停/继续整个队列、移除未运行任务、对失败或完成任务单独重翻。
- 每个任务独立输出，不覆盖源文件；默认输出名使用目标语言前缀和源名。
- DWG 通过 ODA 转为工作 DXF，完成后按用户选择的 DWG 版本输出；DXF 可按用户选择的 DXF 版本保存。
- 应用退出或异常时，将任务输入、状态、重试次数、输出路径和进度写入本地队列状态文件；重启后恢复为可继续状态，未完成的 `running` 任务改回 `queued`。

## 并发与 DeepL 防护

- 初始默认：每个 DeepL API Key 同时最多 **2** 个文件；全局最多 **3** 个文件。
- 不做高并发带宽探测。真实 API 调用会消耗配额且可能触发风控；只在真实验收文件上观察 429、超时和平均响应时间。
- 每个 API Key 使用共享限流器；同一时刻只允许有限翻译请求在飞行中，并在 429/网络错误后指数退避（建议 2、4、8 秒，最多 3 次）。
- DWG 的 ODA 转换串行化，避免多个 ODA 进程抢占临时文件或内存；DeepL 文本请求仍可在文件间并行。

## 界面验收范围

- 采用已确认的“顺时针旋转品字形”布局：左上翻译队列、左下实时日志、右侧翻译设置贯穿全高；左侧高度中队列占 70%，日志占 30%。
- 添加文件、选择输出目录、批次统一语言方向、输出格式与 DWG/DXF 版本。
- 可见的队列顺序、任务状态、文件级进度、整体进度条与百分比。
- 启动、暂停、继续、移除、失败重试、单文件重翻、成功/失败提示。
- 每个任务显示输出路径、错误摘要和可复制的完整日志。

## 自动验证

1. 队列状态序列化与恢复；运行中任务重启后能安全重排队。
2. 顺序调度、暂停/继续、移除、重试次数和单项重翻。
3. 输出格式、版本及 `fr_`/`en_`/`zh_` 前缀。
4. 限流、429 退避和一次失败后成功的重试路径。

## 真人端到端验证

使用至少一份 DXF 与一份 DWG，依次执行中文→法语、法语→中文、中文→英语、英语→中文：

1. 入队多个文件，确认按序显示；以默认并发 2 启动。
2. 任务运行中暂停、恢复、移除一个未运行项，并对一个完成项重翻。
3. 人为制造一次可恢复的网络/API 失败，确认退避重试、错误提示和不中断其他任务。
4. 中途退出并重启，确认未完成项可恢复且不会重复覆盖输出。
5. 使用 CAD 查看器打开全部成功输出，确认 DXF/DWG 格式、所选版本和译文文字正常。

在 UI 方案确认前，不实现本功能。
