# 语言资产库

软件将可编辑语言数据保存在本机的 `~/.cad_translator_language_assets.sqlite3`，不上传术语、翻译记忆或用量记录。

## 专业分类与翻译优先级

可选专业分类为通用、电气、暖通、给排水、建筑、装饰、幕墙。同一条完整 CAD 文字按以下顺序处理：所选专业方向术语、通用方向术语、所选专业内置 YAML 术语、通用内置 YAML 术语、所选专业翻译记录、通用翻译记录、DeepL 或 Azure Translator。专业分类只在本地匹配，不发送给翻译服务；幕墙无专用词条时自动回退通用值。

术语和翻译记录均按语言方向保存，完整文字精确匹配且大小写不敏感。仅当文本由拉丁字母与 `.`, `-`, `_` 组成、并且去除分隔符后至少有两个字母时，点号、连字符和下划线会视为等价；例如 `S.A.S`、`s-a-s`、`S_A_S`、`SAS` 命中同一条。含数字的编号和普通短语不套用该规则。

## 方向术语库

四个方向各有一份可编辑术语库。用户从翻译记录确认译文后，可将其升为方向术语；方向术语会覆盖内置术语、翻译记录和翻译服务。旧“我的术语”会在升级时迁入对应方向术语库。

## 内置术语

“内置术语”标签会显示当前软件随附的四个 YAML 术语表（中法、法中、中英、英中）。它们是只读基础词库，始终参与翻译；选择“复制到方向术语库”后，可以创建优先级更高的可编辑覆盖项。

## 翻译记录

每次成功调用 DeepL 或 Azure 后，软件记录原文、译文、方向、服务来源、首次时间、最后修改时间和命中次数。记录可按方向、原文/译文关键词、服务来源、人工修正状态，以及最近 10 个图纸文件名筛选，并分页查看全部历史。人工修正不会被后续服务结果覆盖；任何修改会立即使本次运行的翻译缓存失效。

## 旧项目术语包

已有 `.hcterms.json` 项目包保留在磁盘，不删除、不改写，但 v1.9.0 起不再加载或参与翻译。

## 服务用量

DeepL 面板在打开时使用当前 Key 调用官方用量接口，显示真实字符使用量和上限。Azure F0 面板显示本软件本月实际发送的字符与请求数、2,000,000 字符的 F0 估算额度以及收到 `403001` 后的超额标记；Azure 门户账单或其他应用产生的用量不会计入本机统计。
