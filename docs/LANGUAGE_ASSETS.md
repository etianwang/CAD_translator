# 语言资产库

软件将可编辑语言数据保存在本机的 `~/.cad_translator_language_assets.sqlite3`，不上传术语、翻译记忆或用量记录。

## 翻译优先级

同一条完整 CAD 文字按以下顺序处理：项目术语包、我的术语、内置 YAML 术语、翻译记忆、DeepL 或 Azure Translator。术语和翻译记忆都只对清洗后的完整文字精确匹配；项目术语可以额外限定“图层包含”条件。

## 项目术语包

在“术语与记忆”窗口中选择或新建 `.hcterms.json` 文件。该文件可随 CAD 项目发送给同事，且优先于本机“我的术语”。项目术语包只保存术语，不包含 API Key、翻译记忆或任何 CAD 文件。

## 内置术语

“内置术语”标签会显示当前软件随附的四个 YAML 术语表（中法、法中、中英、英中）。它们是只读基础词库，始终参与翻译；选择“复制到我的术语”或“复制到项目”后，可以创建优先级更高的可编辑覆盖项。

## 翻译记忆

每次成功调用 DeepL 或 Azure 后，软件记录原文、译文、方向、图层、服务来源和命中次数。人工编辑的记忆不会被后续 API 结果覆盖；可将任意记忆一键提升为术语。

## 服务用量

DeepL 面板在打开时使用当前 Key 调用官方用量接口，显示真实字符使用量和上限。Azure F0 面板显示本软件本月实际发送的字符与请求数、2,000,000 字符的 F0 估算额度以及收到 `403001` 后的超额标记；Azure 门户账单或其他应用产生的用量不会计入本机统计。
