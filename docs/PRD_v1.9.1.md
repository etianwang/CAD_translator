# v1.9.1 PRD：专业分类术语

## 目标

在不向 DeepL 或 Azure 发送上下文提示的前提下，让用户为单次或批量翻译选择本地“专业分类”，从同一语言方向术语库中选取对应的专业译法。

## 范围

- 四个现有及未来新增语言方向都支持固定分类：通用、电气、暖通、给排水、建筑、装饰。
- 每个方向只有一份 YAML 和一份可编辑方向术语库；YAML 使用 `meta` 与按原文组织的 `terms`，每条包含 `general` 及可选专业字段。
- 用户方向术语、翻译记录新增专业分类字段；现有数据迁到 `general`。
- 查找顺序：所选专业用户术语 → 通用用户术语 → 所选专业内置术语 → 内置通用术语 → 所选专业记录 → 通用记录 → 翻译服务。
- 专业分类仅做完整标签精确匹配；未命中时正常回退。启动应用始终重置为通用；批量在开始时锁定分类。
- 设置面板及语言资产术语管理均提供专业分类选择；术语库搜索仍按原文定位同一条术语。

## 非目标

- 不向翻译服务传递专业分类或提示词。
- 不按专业拆分 YAML、SQLite 文件或方向术语库。
- 本版不以凑数方式扩写未校验的中英术语；后续基于图纸和可核对资料扩充。

## 成功标准

1. 选择暖通时，专业词条覆盖通用词条；选择通用时仅使用通用词条。
2. 用户专业术语优先于所有内置术语；通用用户术语可作为专业选择的兜底。
3. 专业翻译记录不污染其他专业；通用记录可作为兜底。
4. 单文件和批量请求携带专业分类；批量已开始任务不受界面后续选择影响。
5. 旧术语、旧翻译记录迁为通用且不会丢失。
