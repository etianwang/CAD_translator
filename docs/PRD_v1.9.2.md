# v1.9.2 PRD：智能合并拆行文字

## 目标

为 CAD 图纸中被拆为多个相邻 `TEXT` 实体的短标签和房间名提供一项可选的本地预处理能力。开启后，软件先将符合严格几何规则的拆行文字合并为一个完整短语翻译，再按原行数写回，避免逐行翻译造成语义断裂。

## 范围

- 翻译设置增加 `智能合并拆行文字` 开关，默认关闭；单文件请求携带该设置，批量任务在开始时锁定该设置。
- 只处理模型空间和图纸布局中的普通 `TEXT` 实体；不处理 `MTEXT`、属性文字、尺寸文字、表格、块定义或长段落。
- 仅合并同一图层、同一文字样式、同一高度和旋转角度，且在垂直方向紧邻、水平位置对齐的短文本行；单组最多三行、合并前后均受短标签长度限制。
- 每个合并组只执行一次既有术语/记录/翻译服务查找，继续使用当前专业分类和语言方向逻辑；不向 DeepL 或 Azure 发送额外上下文。
- 翻译结果按原有行数重新分配：优先按单词边界拆分，中文等无空格结果按字符比例拆分，保留原实体和其位置。
- 不满足规则的实体继续逐条翻译，行为与关闭开关时一致。

## 非目标

- 不自动合并段落、注释、说明文字或任意彼此接近的 CAD 文字。
- 不修改源图纸中的实体数量、图层、样式、旋转或坐标。
- 不引入 OCR、模糊语义匹配或新的第三方依赖。

## 成功标准

1. 默认关闭时，所有 `TEXT` 保持原有逐实体翻译行为。
2. 开启后，类似 `Salle de` / `Réunion/Salle des` / `Parents` 的相邻房间名会作为完整标签翻译一次，并写回对应的原始行数。
3. 不同图层、样式、尺寸、旋转、未对齐或间距过大的文本不得被合并；`MTEXT` 必须保持原路径。
4. 合并后的翻译仍遵循 v1.9.1 的专业分类术语优先级。
5. 单文件和批量界面均可设置该选项；已开始的批量任务不受后续界面修改影响。
